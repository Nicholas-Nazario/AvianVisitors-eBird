ABOUT

This project is a fork of Teddy Warner's Avian Visitors project. I live in NYC and while there are many birds to observe here, most of them are not outside my window. This fork uses CornellLab eBird observation data to visualize birds near any lat/lon location or hotspot. I hope you enjoy it 😁🦤

    the birds

    The birds outside your window

    Each observed species shows up as an illustration in the collage, sized by how many birds were observed.

    the stats

    How Observed Species works

    Observed Species shows the species observed in the selected time window. Each column is one species. Its position along the bottom is based on when it was last observed, from oldest to newest.

    The square's height shows how many birds of that species were observed. A taller square means more birds. The graph may show only the most-observed species when there are too many to fit.

    the stats

    How Top Species works

    Top Species lists the five species with the highest bird counts in the selected time window.

    The number next to each species is the total number of birds observed. It counts birds, rather than simply counting observation records.

    time windows

    How the time selector works

    The eBird recent-observations API accepts its back window in whole days. We request the broader day-based set, then use each observation's obsDt timestamp to filter it in our API.

    We offer 24-hour, 7-day, 14-day, and 30-day windows. The API request covers the broader day-based range, then our API filters observations by timestamp.

    Learn more about the eBird API →

    location settings

    Distance or hotspot?

    Distance searches for recent eBird observations within the selected radius of your latitude and longitude. Use it to see birds reported anywhere near a point.

    Hotspot searches only the eBird hotspots you select. Use it when you want observations tied to specific birding locations rather than the whole surrounding area.

    The coordinates and distance are also used to find nearby hotspots. You can select up to five of them at a time.
